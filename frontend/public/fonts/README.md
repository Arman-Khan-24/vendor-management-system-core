# Interface font

Manrope, variable weights 400–800, from Google Fonts. Latin and Latin Extended subsets are served locally as WOFF2; other scripts use the system sans-serif fallback. No font requests leave the application at runtime.

Source: https://github.com/google/fonts/tree/main/ofl/manrope
