# Statement font

`NotoSansDevanagari.ttf` is the unmodified Noto Sans Devanagari variable font from Google Fonts, with its original filename shortened for application use.

- Source: https://github.com/google/fonts/tree/main/ofl/notosansdevanagari
- Original font: https://raw.githubusercontent.com/google/fonts/main/ofl/notosansdevanagari/NotoSansDevanagari%5Bwdth,wght%5D.ttf
- Copyright: 2022 The Noto Project Authors (https://github.com/notofonts/devanagari)
- License: SIL Open Font License 1.1; see `OFL-NotoSansDevanagari.txt`.

The font supports Devanagari, Latin, digits, and the Indian rupee symbol. It is embedded into generated statement PDFs. The backend build copies this directory to `dist/assets/fonts`; PDF generation performs no font downloads at runtime.
